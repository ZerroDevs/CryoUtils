# CryoUtils v0.0.101

This release introduces the compact **CryoUtils Lite** build, eliminates all Windows Forms, `SkiaSharp`, and `Microsoft.Windows.SDK.NET` dependencies for a dramatically smaller footprint (~34 MB lighter Lite setup / ~56 MB lighter Full offline), overhauls **Screenshot-Only Mode (Lite)** and tray responsiveness, adds `--capture` one-shot mode, and lazy-loads dashboard tabs for fast startup and lean memory use.

---

## What's New & Improved

### 1. CryoUtils Lite Edition & Dependency Removal
- **Zero Windows Forms (`UseWindowsForms=false`):** Replaced tray hosting and context menus with native Win32 `Shell_NotifyIconW` and dark RTL-aware owner-drawn popup menus (`TrayIconManager`), replaced `NativeWindow` hotkeys with `HWND_MESSAGE` + WPF `KeyInterop` (`GlobalHotkeyService`), and replaced `ColorDialog` with native Win32 `ChooseColorW` (`ColorDialogHelper`).
- **Zero `SkiaSharp`:** Migrated all image conversions, resizing, compression, and metadata stripping to Windows WIC (`ImageIO`, `ImageProcessingService`), added `SimpleWebpEncoder` (pure managed RIFF/VP8L lossless WebP) and `SimplePdfWriter` (zlib FlateDecode PDF export).
- **Zero `Microsoft.Windows.SDK.NET`:** Targeted `net10.0-windows` directly with a compact COM ABI interop layer (`WinRtBridge`) for offline OCR, PDF rendering, and Windows Graphics Capture plus direct Media Foundation H.264/AAC encoding (`CaptureEngine`, `MediaConversionService`, `ReplayRemuxer`, `WebcamCaptureService`).
- **Smaller embedded icon & NTFS post-install compression:** Downscaled `CryoUtils-Icon.png` (`2048x2048` -> `256x256`) and removed unused `CryoUtils.jfif`, saving ~1.5 MB inside `CryoUtils.dll` and cutting ~16 MB per decoded window bitmap, paired with fixed `compact.exe /c /s:"{app}" /i /q` compression after install.
- **Edition-matched auto-updater:** `UpdaterService` detects self-contained (`coreclr.dll`) vs Lite installs cleanly and keeps `CryoUtils-Setup-<version>.exe` ahead of `CryoUtils-Setup-Lite-<version>.exe` so `v0.0.100` in-app updaters stay on Full Offline while Lite users stay on Lite.

### 2. Screenshot-Only Mode (Lite), Tray Clicks & Lower Memory Use
- **Fixed tray left & double-click routing:** Single left-clicking the tray icon in **Screenshot-Only Mode** (or when left-click is set to **Capture**) starts screenshot capture directly; rapid double-clicks no longer pop open the dashboard underneath active captures.
- **Immediate Screenshot-Only UI & Compact Overview:** Entering Screenshot-Only Mode detaches the heavyweight `Tools` tab, displays the **Screenshot-Only Mode (Lite)** status banner and one-click **Restore** button, collapses non-screenshot Quick Launch tiles and module cards (`Color Picker`, `Window Pinner`, `Compressor`, `Clipboard History`) cleanly instead of leaving dimmed cards, keeps `OCR & Copy` + `QR` active, and trims background recent-capture image caches when returning to tray.
- **One-shot `--capture` CLI & Repeat Last Region:** Capture via `CryoUtils.exe --capture` with zero background RAM resident after completion, or repeat the last selection via hotkey (`Shift+Hotkey`) or tray menu.
- **Lazy-loaded dashboard tabs & responsive `MemoryTrimService`:** Secondary tabs (`Screen Capture`, `Tools & Utilities`, `Hotkeys`, `Settings`) instantiate on demand; `MemoryTrimService` adds `PauseForInteraction()` (`1200 ms`) across tab switches, menus, and settings changes plus a `5 s` `MinDeactivatedInterval` anti-bounce cooldown.
- **In-place annotation editing:** Double-click placed text labels to edit inline and scroll mouse wheel while an annotation is selected to adjust stroke/font/swatch live.

### 3. Security, Capture UX & Workflow Polish
- **Verified in-app updater (SHA-256):** `UpdaterService` downloads the release's matching `.sha256` file over HTTPS and verifies the downloaded setup before execution, deleting any mismatched or unverified payload.
- **Single-instance tray guard:** Launching CryoUtils a second time signals and focuses the running tray/dashboard instance instead of spawning duplicate tray icons, while short-lived `--action`, `--capture`, `--uninstall-cleanup`, and `--unregister-context-menu` helpers stay exempt.
- **Instant Active-Window Snap (`Ctrl+Alt+S` / Tray):** Captures the focused foreground window directly to clipboard (and optional auto-save) in 0 ms with zero overlay freeze frame.
- **Drag-out screenshots, one-click `OCR & Copy` (`Shift+O`), Pretty Frame (`F`), and Ghost Pins (`G`):** Drag captures directly from the **Recent captures** strip or overlay **Drag** handle into Discord/browsers/apps, run one-click **OCR & Copy** without opening a window, wrap exports in optional rounded-corner gradient frames with soft drop shadows, and toggle `WS_EX_TRANSPARENT` ghost mode on `PinWindow` (`G`) with tray recovery controls.

## Download & Verify

- **Installer — Full Offline (Recommended for zero extra downloads):** Download `CryoUtils-Setup-0.0.101.exe` and verify against `CryoUtils-Setup-0.0.101.exe.sha256`. Installs per-user under `%LOCALAPPDATA%\Programs\CryoUtils` without UAC.
- **Installer — Lite (Smallest download, auto-installs .NET 10 if missing):** Download `CryoUtils-Setup-Lite-0.0.101.exe` (`CryoUtils-Setup-Lite-0.0.101.exe.sha256`).
- **Portable Archives:** Download `CryoUtils-0.0.101-win-x64.zip` (Full self-contained) or `CryoUtils-Lite-0.0.101-win-x64.zip` (requires .NET 10 Desktop Runtime x64), verify the matching `.sha256` file, extract, and run `CryoUtils.exe`.
