# CryoUtils v0.0.100

First public release of **CryoUtils** — a fast, lightweight, offline-first Windows desktop utility suite built on **.NET 10 LTS** (`net10.0-windows10.0.19041.0`) for screenshot capture, live MP4/GIF recording, Instant Replay, Windows Explorer right-click file conversions & tools, offline OCR, QR code scanning/generation, color picking, window pinning, compression, clipboard history, PDF/media jobs, and developer utilities.

---

## Complete Feature Summary

### 1. Screen Capture & Annotation Overlay
- **Global Hotkeys & Multi-Monitor Freeze Frame:** Configurable capture hotkey (defaults to `PrintScreen`, supports standalone `Home` and contested-hotkey fallback `Ctrl+Shift+S`), PerMonitorV2 DPI-aware per-monitor overlays over a physical-pixel snapshot, dimmed backdrop, crosshair, drag region with live size badge, double-click window selection, `Ctrl+A` full-monitor selection, 8 resize handles, and delayed capture countdown (`CountdownWindow`).
- **Streamlined Toolbar & `1`–`0` Shortcuts:**
  - Starts in **Select** mode by default (no extra Select icon on the rail).
  - Clicking an active tool button or pressing its shortcut again toggles directly back to **Select** (`V` also forces Select).
  - **Number Shortcuts (`D1`–`D0` / `NumPad1`–`NumPad0`) + Letter Aliases:**
    - `1` / `P`: Pen (freehand polyline)
    - `2` / `L`: Line (`Shift` 45°/90° angle snap)
    - `3` / `A`: Arrow (sleek pointed arrowhead with trimmed flat-capped shaft)
    - `4` / `R`: Rectangle (`Shift` square)
    - `5` / `E`: Ellipse
    - `6` / `S`: Spotlight (dims surroundings outside ellipse)
    - `7` / `K`: Redaction (irreversible opaque black stroke)
    - `8` / `H`: Highlighter (semi-transparent wide marker)
    - `9` / `T`: Inline EN/AR Text (auto-detects RTL text direction)
    - `0` / `B`: Irreversible Blur / Pixelate (baked directly into exported bitmap)
    - `N`: Auto-increment circular Step Number badges
- **Interactive Annotation Editing & Precision Controls:**
  - Dashed selection outlines and draggable handles for selected annotations: circular tip/tail endpoint handles on `Line`/`Arrow` (`Shift` snap supported), 8 resize handles on `Rectangle`/`Ellipse`/`Spotlight`/`Blur` (re-renders pixelation live), `Delete`/`Backspace` removal, and vector `Ctrl+Z` / `Ctrl+Y` undo/redo.
  - `Text` (`9`) and `Step` (`N`) fall back cleanly to dragging a selection when no region exists yet.
  - Optional pixel magnifier loupe with HEX color readout & coordinates (active before/during initial region drag and annotation placement, automatically avoiding rails and hiding during freehand strokes).
  - Mouse-wheel stroke thickness adjustment (`Shift+Wheel` for 0.5 px steps) with live size preview, custom color picker & swatch presets, and collision-avoiding floating action rail.
  - **Fast Finish & Safe Cancel:** `Enter` or `Ctrl+C` copies selection, right-click steps back safely (`active input -> active tool -> Select -> deselect -> close`), and `Esc` exits capture immediately.
- **Export & Post-Capture Actions:**
  - Quick/dialog save (`PNG`, `JPG`, `WebP`), Crop / Rotate 90° (re-opens selection as a new editable capture), Stitching **Scrolling Capture**, **Pin to screen** (zoom & opacity wheel), **Print** (`Ctrl+P`), **Scan QR**, and **Upload** (`Ctrl+U` / `Ctrl+D`, optional archiving of copied/uploaded shots).

### 2. Video Recording, Audio, Effects, Trim & Instant Replay
- **Region Video & GIF Recording (`RecordingBarWindow` / `Services/Recording/`):**
  - Record any selected screen region as **MP4** (native `Windows.Graphics.Capture` + Direct3D 11 staging readback + **Media Foundation H.264/AAC** with hardware transform preference and `SoftwareBitmap`/GDI cross-monitor fallbacks) or **GIF** (in-project `GifEncoder`).
  - Live controls for `15 / 24 / 30 / 60 FPS`, resolution (`Source`, `720p`, `1080p`, `1440p`, `2160p`), quality presets (`Low`, `Medium`, `High`, `Custom`), custom bitrate slider (`Auto` or `Custom Mbps`), max duration presets (`1–60 min`), live timer, frame/drop telemetry, estimated output size, Pause/Resume (pauses remove paused gaps cleanly from final MP4 timestamps), click-through 2 px red recording border, `Stop & Save`, `Stop & Copy` (clipboard file drop), and `Cancel`.
- **Audio Capture, Camera & Visual Effects (`RecorderSettingsWindow`):**
  - Separate toggles and **WASAPI device selectors** for System Loopback Audio and Microphone (`WasapiCaptureService` + 48 kHz stereo PCM `AudioMixer` + `AacMftEncoder`, with silent/video-only fallback if AAC/device is unavailable).
  - Optional **Cursor Highlight**, **Click Effects**, **Webcam Bubble** overlay, and **Trim Before Save** (`RecordingTrimWindow` visual start/end trim preview).
- **Instant Replay Buffer:**
  - Always-ready disk-backed circular keyframe-aligned MP4 ring buffer (`%LOCALAPPDATA%\CryoUtils\ReplayBuffer`, configurable `15s`–`10 min`), selectable monitor (`Primary` or `Cursor`), configurable hotkey (default `Ctrl+Shift+R`), tray menu start/stop/save controls (red tray badge indicator while recording/buffering), and lossless remuxing (`ReplayRemuxer` with `MediaComposition` fallback).

### 3. Windows Explorer Right-Click Context Menus (`CryoUtils` & `CryoUtils Convert`)
Per-user right-click shell integration under `HKCU\Software\Classes` (toggleable in Settings, zero UAC, short-lived `--action` workers):

- **Images (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.ico`, `.jfif`, `image`) & `.gif`:**
  - **`CryoUtils` menu:** Resize presets (`50%`, `1920px wide`, `512px max`), Quick compress, Remove background (`_nobg.png`), Trim transparent margins (`_trimmed.png`), Strip EXIF metadata (`_clean.<ext>`), Extract text (OCR), Scan QR code, Copy pixels to clipboard, Pin image to screen, Upload & copy link.
  - **`CryoUtils Convert` submenu:** Convert to `PNG`, `JPG`, `WebP`, `ICO`, Image to `PDF`, Flatten transparency on white (`_flat.jpg`), Extract GIF frames (`_frames/` on `.gif`), Copy Base64 Data URI.
- **PDF Files (`.pdf`):**
  - PDF to PNG (`_pages/`), PDF to JPG (`_pages/`), Compress PDF (`_compressed.pdf`), Convert to Grayscale (`_grayscale.pdf`), Rotate `90°` (`_rot90.pdf`), Rotate `180°` (`_rot180.pdf`), Upload & copy link.
- **Video Files (`.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `video`):**
  - Compress video for Discord (`_compressed.mp4`), Convert video to GIF (`.gif` with progress & cancellation), Extract audio to `MP3`, Mute video (`_muted.mp4`), Save video thumbnail (`_thumb.jpg`), Upload & copy link.
- **Audio Files (`.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg`, `.aac`, `audio`):**
  - Convert to `MP3`, `WAV`, `M4A`, Upload & copy link.
- **JSON, XML & Text Files (`.json`, `.xml`, `.txt`, `.md`, `.csv`):**
  - Pretty-print JSON (`.pretty.json`), Minify JSON (`.min.json`), Pretty-print XML (`.pretty.xml`), Generate QR code from file text (`text-to-qr` with preview & PNG save), Copy `SHA-256` hash, Upload & copy link.
- **All Files (`*`):**
  - Upload & copy link, Copy `SHA-256` hash, Copy `MD5` hash.
- **Folders (`Directory`):**
  - Merge folder images into PDF (`_merged.pdf`), Convert folder images into animated GIF (`.gif` with progress & cancellation), Batch compress all folder images (`_compressed/`).

### 4. Offline OCR & QR Code Suite
- **Local Windows OCR (`OcrResultWindow`):** Uses installed Windows OCR language packs offline (English, Arabic, etc.), preserves line breaks, auto-sizes editable text area, toggles **Code mode** (monospace syntax highlighting + horizontal scroll) and line wrap, displays line/character counts, opens/saves text/code/Markdown files (drag & drop supported), and detects clickable Hex / RGB / RGBA / HSL / HSLA color swatches.
- **Managed QR Encoder & Scanner (`QrCodeService`, `QrResultWindow`):** Built-in offline QR scanning from screen selections or Explorer context menu images and QR generation from text files via `ZXing.Net`, with decoded text copy and clean QR image export.

### 5. Color Picker & Color Studio
- **Global Color Picker (`Ctrl+Shift+C`):** Physical-pixel desktop freeze frame, cursor magnifier grid, live HEX / RGB / HSL readouts, one-click format copy, Esc close, and 10 recent colors synced with dashboard.
- **Color Studio (`Workbench > Colors`):** Extract palettes from captures or screen, WCAG 2.1 contrast checker (ratio + AA/AAA grades), saved contrast pairs, CSS / JSON / Tailwind token exports, and Deuteranopia / Protanopia / Tritanopia color-vision simulation preview.

### 6. Window Pinner & Pinner Workbench
- **Quick Pinning (`Ctrl+Win+T`):** Toggle `WS_EX_TOPMOST` across multiple windows simultaneously, optional click-through 2 px accent border (`PinnedBorderWindow`) and confirmation sound, emergency unpin-all recovery, and automatic clean unpin on exit.
- **Pinner Controls (`Workbench > Pinner`):** Per-window opacity slider (`20–100%`), per-window click-through toggle, process exclusion list, and best-effort pin restore across restarts (bypassable with `--safe-mode`).

### 7. Image & GIF Compressor
- Drag-and-drop or file-picker compressor supporting `PNG`, `JPG/JPEG`, `WebP`, and `GIF` with **Discord 10 MB**, **WhatsApp / Light**, and **Custom** presets, quality and resolution scale sliders, live preview, before/after byte & percent stats, automatic keep-original fallback when output is larger, Save As, and clipboard file copy.

### 8. Clipboard History, Transforms & Plain-Text Paste
- Opt-in clipboard history listener (`Ctrl+Shift+H`, disabled by default; disabling tears down listener and clears RAM cache).
- Text and image clip capture, live search filter, **Named Snippets** manager, sensitive-item auto-clear (tokens/passwords/URLs), configurable item limit (`10–100`) & age expiry, optional Windows DPAPI encrypted text persistence (`clipboard.bin`; images stay memory-only), clip OCR on images, inline **Transform Preview** (`UPPERCASE`, `lowercase`, `Title Case`, `snake_case`, `kebab-case`, `camelCase`, URL encode/decode, Base64, JSON pretty/minify), and global **Plain-Text Paste** (`Ctrl+Shift+V`).

### 9. Desktop Overlay & Workspace Tools
- **Live Draw (`Ctrl+Shift+D`):** Transparent virtual-desktop ink overlay over live apps with Pen, crisp Arrow, Rectangle, Text tools, 5-second auto-fade or persistent ink mode, Undo/Clear, and composited desktop PNG capture.
- **Screen Ruler:** Pixel-accurate horizontal, vertical, diagonal, and region measurements with angle readout, alignment guides, and one-click measurement copy without taking a screenshot.
- **File Shelf:** Floating drop zone for images, PDFs, videos, and folders with drag-out to other apps, batch compress/convert queuing, PDF merge, and file path copy.
- **Built-in Image Editor:** Open/save/convert (`PNG`/`JPG`/`WebP`/`BMP`), rotate ±90°, resize dialog, visual crop (`6`/`C`, `Enter` to apply, `Esc` to clear), Pen (`1`/`P`), crisp Arrow (`2`/`A`), Box (`3`/`R`), Redact (`4`/`K`), Text (`5`/`T`), custom Color picker popup, stroke thickness `-`/`+` & mouse-wheel adjustment (`1–24 px`), Undo/Redo (`Ctrl+Z`/`Ctrl+Y`), and crop-free flattening.
- **Developer Toolbox:** Local JSON/XML pretty & minify, Base64/URL encode/decode, SHA-256 hashing, GUID generation, and live regex tester.

### 10. Cryo Workbench (`Ctrl+Shift+W`)
Unified local workspace (`PowerToolsWindow`) organizing advanced workflows:
- **Library:** Metadata index (`capture-library.json`) referencing original files in your save folder with source app/window info, search, tags, favorites, multi-select open/reveal, and Recycle Bin deletion.
- **Recipes (`WorkflowService`):** Automated post-capture rules triggered on Copy/Save matching source app/title, filename templates, optional resize, save/copy/OCR/upload chaining.
- **Privacy Center:** Choose **catbox.moe** (explicit first-run consent prompt + Settings kill switch) or **Local Uploads** (`%APPDATA%\CryoUtils\uploads` with configurable auto-expiry and local cleanup) plus full upload history.
- **File Actions Queue:** Batch convert/compress/recycle jobs with dry-run previews, custom output directory, overwrite policy, progress/cancel/retry, and confirmation before Recycle Bin moves.
- **PDF & Media Jobs:** PDF range extract, merge, split, reorder, rotate, and OCR; MP4 trim and GIF start/end frame range extraction.
- **Diagnostics:** Bounded local logs (`logs/cryoutils.log`), unhandled exception capture, log viewer, and `--safe-mode` recovery startup.

### 11. Dashboard, Tray, Performance, Localization & Updater
- **Compact Dashboard UI:** `Overview`, `Screen Capture`, `Tools & Utilities`, `Hotkeys`, and `Settings` tabs; collapsed-by-default compact **Activity Center** (storage/retention, uploads, workflows, jobs, pins, quick actions); unified closeable **Recent captures** (`This session` / `All time` async thumbnail cache with circular count badge).
- **Lightweight Tray Lifecycle:** Built on **.NET 10 LTS** (`asInvoker`, zero UAC, zero telemetry), low idle RAM/CPU footprint (`MemoryTrimService`, on-demand visual caches, automatic tray working-set trimming on background/minimize), packaged crisp multi-size tray icon, Dark/Light/System live theme switching, full English & Arabic (`العربية` RTL) localization, CLI flags (`--background`, `--safe-mode`, `--action`, `--uninstall-cleanup`), atomic settings saves (`settings.json` + JSON export/import/reset), and built-in GitHub Releases updater with rollback backup support.

## Download & Verify

- **Installer (Recommended):** Download `CryoUtils-Setup-0.0.100.exe` and verify against `CryoUtils-Setup-0.0.100.exe.sha256`. Installs per-user under `%LOCALAPPDATA%\Programs\CryoUtils` without admin elevation.
- **Portable Archive:** Download `CryoUtils-0.0.100-win-x64.zip`, verify against `CryoUtils-0.0.100-win-x64.zip.sha256`, extract, and run `CryoUtils.exe`.
