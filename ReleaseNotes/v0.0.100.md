# CryoUtils v0.0.100

First public release of **CryoUtils** — a fast, lightweight, offline-first Windows utility suite built on **.NET 10 LTS** (`net10.0-windows10.0.19041.0`) for screen capture & annotation, recording, OCR, color picking, window pinning, compression, clipboard history, PDF/media utilities, and developer tools.

---

## Highlights & Feature Catalog

### 1. Screen Capture, Annotations & Recording
- **Hotkeys & Multi-Monitor Capture:** Configurable global capture hotkey (default `PrintScreen`, supports standalone `Home` and contested-hotkey fallback guidance), multi-monitor PerMonitorV2 DPI freeze-frame overlay, dimmed canvas, crosshair, double-click window selection, and `Ctrl+A` full-monitor selection.
- **Toolbar & Number Shortcuts (`1`–`0`):**
  - Default mode starts cleanly in `Select` (no dedicated Select button cluttering the rail).
  - Clicking any active tool button or pressing its shortcut again toggles directly back to `Select` (`V` also forces `Select`).
  - **1–10 Numbered Shortcuts** (plus letter aliases):
    - `1` / `P`: Pen (freehand polyline)
    - `2` / `L`: Line (`Shift` 45°/90° snap)
    - `3` / `A`: Arrow (sleek pointed arrowhead with trimmed flat-capped shaft)
    - `4` / `R`: Rectangle (`Shift` square)
    - `5` / `E`: Ellipse
    - `6` / `S`: Spotlight
    - `7` / `K`: Redaction (irreversible opaque black stroke)
    - `8` / `H`: Highlighter
    - `9` / `T`: Inline EN/AR Text (auto RTL detection)
    - `0` / `B`: Irreversible Pixel Blur / Pixelate
    - `N`: Auto-increment Step Number badges
- **Interactive Selection & Editing:**
  - Drag or resize selection with 8 handles and live size badge; `Text` (`9`) and `Step` (`N`) also support starting a region drag when no selection exists yet.
  - Dashed outline and draggable handles for selected annotations (circular endpoint handles on `Line`/`Arrow` with `Shift` snap, 8 resize handles on `Rectangle`/`Ellipse`/`Spotlight`/`Blur`), `Delete`/`Backspace` removal, and vector `Ctrl+Z` / `Ctrl+Y` undo/redo.
  - Custom color swatches & picker, mouse-wheel stroke thickness with live preview, optional pixel magnifier loupe (active before/during region drag and annotation placement, auto-hiding over rails and freehand ink).
  - Safe right-click step-back (`active draw -> active tool -> Select -> deselect -> close`) and immediate `Esc` exit.
  - `Enter` or `Ctrl+C` to copy & close, quick/dialog save (`PNG`, `JPG`, `WebP`), crop/rotate 90°, scrolling capture stitcher, pin-to-screen (zoom & opacity wheel), and print (`Ctrl+P`).
- **GIF / MP4 Screen Recorder & Replay:** Region recording bar (15 / 24 / 30 FPS, live timer, estimated output size, pause/resume, click-through red recording border, stop & save or stop & file-drop copy, replay segment ring with Media Foundation H.264/AAC encoding).
- **Offline OCR Viewer:** Windows offline OCR, auto-sized editable preview, code syntax highlighting mode, and clickable Hex/RGB/HSL color swatches.

### 2. Color Picker
- Global hotkey (`Ctrl+Shift+C`), full-screen freeze frame, cursor magnifier grid, live HEX / RGB / HSL readout, one-click format copy, Esc close, and recent 10 color history.

### 3. Window Pinner
- Global hotkey (`Ctrl+Win+T`), `WS_EX_TOPMOST` pinning across multiple windows, optional click-through 2 px border and sound, per-window opacity (20–100%), process exclusion list, and exit/restart restoration.

### 4. Image & GIF Compressor
- Drag-and-drop dashboard compressor supporting `PNG`, `JPG/JPEG`, `WebP`, and `GIF` with **Discord 10 MB** preset, **WhatsApp / Light** preset, Custom quality & scale sliders, live decoded preview, before/after byte & percent savings, automatic skip when output exceeds original size, Save As, and clipboard file copy.

### 5. Clipboard History & Plain-Text Paste
- Opt-in listener (`Ctrl+Shift+H`), text and image clips in memory (plus optional DPAPI-encrypted text persistence and expiry), search, named snippets, live preview transforms (`Upper`, `Lower`, `Title`, `Snake`, `Kebab`, `Camel`, `URL encode/decode`, `Base64`, `JSON`), clipboard image OCR, sensitive-item auto-clear, and formatted-to-plain paste.

### 6. Dashboard, Workbench & Desktop Tools
- **Custom Dark/Light/System Chrome:** Overview, Screen Capture, Tools & Utilities, Hotkeys, and Settings tabs; English & Arabic (`العربية`) full RTL localization.
- **Compact Activity Center & Unified Recent Captures:** Collapsed-by-default Activity Center with storage/retention summary, uploads, workflows, file jobs, pinned windows, and quick actions, paired with a closeable `Recent captures` strip supporting `This session` / `All time` async thumbnail loading.
- **Live Draw (`Ctrl+Shift+D`):** Transparent virtual-screen ink overlay with Pen, clean Arrow, Rectangle, Text, fade-after-5s toggle, undo/clear, and capture.
- **Screen Ruler:** Horizontal, vertical, diagonal, and region measurements with angle/pixel readout copy and click-to-place guides.
- **File Shelf:** Floating drop target with drag-out, batch compress/convert, PDF merge, and path copy.
- **Built-in Image Editor:** Open/save/convert (`PNG`/`JPG`/`WebP`/`BMP`), rotate, resize, crop (`6`/`C`, `Enter` to apply, `Esc` to clear), annotate with Pen (`1`/`P`), Arrow (`2`/`A`), Box (`3`/`R`), Redact (`4`/`K`), Text (`5`/`T`), custom Color picker, stroke thickness controls & mouse-wheel adjustment, and Undo/Redo (`Ctrl+Z` / `Ctrl+Y`).
- **Developer Toolbox & Workbench Modules:** Local JSON/XML formatter, Base64/URL/SHA-256/MD5/GUID/regex tools, capture library tagging/favorites/bulk actions, post-capture automation recipes, local/Catbox privacy upload controls, Color Studio (palette extraction, contrast checker, CSS/JSON/Tailwind export, CVD simulation), PDF range extract/merge/split/rotate/OCR, Video trim / GIF frame range tools, and bounded diagnostics with `--safe-mode`.

### 7. System Tray, Privacy, Packaging & Updater
- Packaged multi-size tray/app icon, configurable left-click & dark localized right-click menu, low idle RAM/CPU footprint (`asInvoker`, zero UAC prompts, no telemetry).
- Built-in GitHub release checker (`ZerroDevs/CryoUtils`) with progress download, rollback backup restore, and SHA-256 verified installers.

## Download & Verify

- **Installer (Recommended):** Download `CryoUtils-Setup-0.0.100.exe` and verify against `CryoUtils-Setup-0.0.100.exe.sha256`. Installs per-user under `%LOCALAPPDATA%\Programs\CryoUtils` without admin elevation.
- **Portable Archive:** Download `CryoUtils-0.0.100-win-x64.zip`, verify against `CryoUtils-0.0.100-win-x64.zip.sha256`, extract, and run `CryoUtils.exe`.
